# Boton

Botones en píldora: el principal en `acento`, el secundario con borde `hairline` y el enlace de texto con "›".

- **Principal:** una sola vez por pantalla, para la acción que vende ("Solicitar diagnóstico"). Fondo `acento`, texto `sobre-acento`.
- **Secundario:** acciones de apoyo. Fondo transparente, texto `texto`, borde `hairline`.
- **Enlace:** para ir a otra parte ("Ver la galería ›"), en `acento`.
- Siempre `radius-pill`, mínimo 44 px de alto, texto en Geist 17 px.
- Foco de teclado: anillo de 2 px en `foco` con 3 px de separación.
- Copy en verbo y corto. Nunca "Haz clic aquí" ni signos de admiración.
