# Portada

La portada de stringwebs.com con la identidad nueva, en siete partes que alternan Noche y Pared.

1. **Barra:** logo con cursor, Sistemas · Productos · Galería · Nosotros, y "Solicitar diagnóstico".
2. **Inicio:** etiqueta mono, titular "Software hecho con oficio. Y con arte.", línea de apoyo, botón principal y enlace a la galería. Abajo, la Ciudad con la luna; el arte nunca sube hasta el texto.
3. **Primera cuerda** a lo ancho, con el botón de sonido.
4. **Galería** en Pared: STRING, el sistema para gimnasios y "Tu negocio".
5. **Tres principios**, cada uno con su cuerda: Diseño propio · Hecho para durar · Probado en casa.
6. **Cierre:** "Cuéntanos qué necesita tu negocio." y el botón principal.
7. **Pie:** logo chico, correo y "Hecho en la Ciudad de México".

En el sitio real las cuerdas vibran y suenan (componente Cuerda); en esta vista previa están quietas. La versión interactiva completa está en el lienzo STRING — Territorios, página Premium, tablero "Premium + arte".
