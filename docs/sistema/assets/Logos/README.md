# Logos

Todas las versiones del logo del cursor, dibujadas con la letra real de Anton convertida a trazo (no necesitan la fuente instalada). **Cursor B (28 oct):** la I es un bloque de terminal con la I en negativo, en forma de puntero; el bloque va calado, así que la I toma el color del fondo.

| Archivo | Cuándo |
| --- | --- |
| `string-noche.svg` | Logo principal sobre noche: letras `#F5F5F3`, bloque `#50FF05`, fondo `#000000` con su espacio libre. Sitio, redes, presentaciones |
| `string-pared.svg` | Logo principal sobre claro: letras `#111214`, bloque `#1A7F00`, fondo `#F4F2EC`. Propuestas, facturas, impresos |
| `string-una-tinta.svg` | Toda la palabra y el bloque en `#111214`, sin fondo; la I queda calada. Sellos, láser, bordado, cualquier lugar sin color |
| `string-firma-gris.svg` | Toda la palabra y el bloque en `#5E5A52`, sin fondo; la I queda calada. La firma "by STRING" dentro de Boaz y de cada producto |
| `string-icono.svg` | El bloque verde con la I en negativo, en un cuadrado noche con esquinas de 112/512. Se lee a 16 px. Favicon, app, avatar |

Los archivos son estáticos: el parpadeo del bloque se hace en la página con CSS (ver el componente Logo).
